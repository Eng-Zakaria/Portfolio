🏗️ Concurrency Architecture

How It Works
FastAPI
Async event loop handles thousands of network connections simultaneously
Semaphore
Limits active Ollama generations to 4 (matches OLLAMA_NUM_PARALLEL)
Thread Pool
Blocking operations (embedding, Redis) offloaded via asyncio.to_thread()
Queue Timeout
Requests waiting >30s get 503 + Retry-After (graceful degradation)

💡 Key Insights

✅ Stable Under Load
System handled 100 concurrent requests with 100% success rate. No crashes, no data loss.
⚠️ Latency Increases Non-Linearly
With 4 parallel slots and ~5s avg generation, each request waits in queue. 30 concurrent users = ~15s avg latency.
🎯 Primary Bottleneck: Ollama CPU
GPU acceleration would provide 10-50x speedup. Without GPU, scaling means adding replicas (linear cost).
🚨 503 Backpressure Rarely Triggered
With 30s timeout, the semaphore rarely rejects requests. Users wait patiently instead of getting fast feedback. Consider lowering to 15s for better UX.

🎯 Recommendations

1. Monitor Health Endpoint
Watch generation_in_flight vs generation_capacity. When they match consistently, you're saturated.
2. Scale Horizontally at 50+ Users
Add app replicas when avg latency exceeds 10s. Each replica = +1.5 req/s capacity.
3. Lower Queue Timeout for Better UX
Change GENERATION_QUEUE_TIMEOUT=15 in .env. Users prefer fast 503 + retry over hanging for 30s.
4. Consider GPU or External LLM API
For >100 concurrent users, CPU inference becomes prohibitively expensive. GPU or cloud API (OpenAI, Anthropic) scales infinitely.

import requests, time
from concurrent.futures import ThreadPoolExecutor

base = 'http://localhost:8000'
results = []

def make_req(i):
    t0 = time.time()
    r = requests.post(f'{base}/api/chat',
                      json={'query': 'Show me offers', 'session_id': f'test-{i}'},
                      timeout=120)
    return {'status': r.status_code, 'latency': time.time() - t0}

with ThreadPoolExecutor(max_workers=30) as pool:
    futures = [pool.submit(make_req, i) for i in range(100)]
    results = [f.result() for f in futures]

ok = sum(1 for r in results if r['status'] == 200)
print(f'{ok}/100 successful, {len(results)/max(sum(r["latency"] for r in results)/100, 0.001):.2f} req/s')
"
