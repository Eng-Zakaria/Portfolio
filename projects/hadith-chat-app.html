The Problem

Finding accurate Hadith references for specific questions requires extensive knowledge of Islamic jurisprudence and access to large text collections. Existing solutions either lacked proper Arabic NLP support or provided inaccurate results due to poor retrieval mechanisms.

The goal was to build a chatbot that could understand Arabic questions about Hadith and provide accurate, sourced responses from a comprehensive knowledge base.

Architecture

Data Pipeline

  • Hadith Corpus Collection: Aggregated from multiple authenticated sources (Sahih Bukhari, Muslim, Abu Dawud)
  • Preprocessing: Cleaned Arabic text, normalized diacritics, and extracted hadith numbers for citation
  • Chunking Strategy: Split into contextually coherent paragraphs with metadata (collection, book, hadith number)
  • Embedding Generation: Used AraBERT v2 for Arabic-specific semantic embeddings
  • Vector Storage: Indexed in Qdrant with collection metadata for filtering

Retrieval Optimization

  • Query Expansion: Added synonyms and related terms for better retrieval
  • Reranking: Cross-encoder reranking to improve relevance of top results
  • Context Window: Tuned retrieval depth and context size for optimal responses
  • Citation Format: Standardized output with collection, book, and hadith number

Django Backend

  • API Layer: RESTful endpoints for query submission and results
  • Streaming Responses: Implemented server-sent events for real-time chat interface
  • Session Management: Maintained conversation context across messages
  • Rate Limiting: Prevented abuse with per-user rate limiting
  • Feedback System: Users could rate responses to improve quality

Challenges & Solutions

Challenge: Arabic NLP Complexity

Arabic text has complex morphology, diacritics, and right-to-left rendering issues.

Solution: Specialized Processing

Implemented Arabic-specific tokenization, normalized diacritics for search, and handled RTL rendering in the frontend.

Challenge: Retrieval Accuracy

Hadith queries require high precision to avoid incorrect religious guidance.

Solution: Multi-Stage Filtering

Implemented cascading filters: first retrieve relevant passages, then verify authenticity chain, then rank by relevance.
