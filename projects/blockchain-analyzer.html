The Problem

Blockchain forensic analysis requires processing large volumes of Ethereum transaction data to identify suspicious patterns like chain hopping, smurfing, and peel chains. The research question was whether graph databases (Neo4j) or batch processing engines (PySpark) were better suited for real-time threat detection and pattern analysis.

Traditional batch processing struggles with relationship-heavy queries that require traversing multiple transaction hops, while graph databases excel at these operations but may not scale as efficiently for simple aggregations.

Benchmarking Results

The platform includes a comprehensive benchmarking module that compares Neo4j and PySpark across three key operations using 1,000 transactions:

  • Multi-hop Traversal: Neo4j was 73.42x faster than PySpark, demonstrating superior performance for relationship-heavy queries
  • Suspicious Pattern Detection: Neo4j was 18.88x faster for identifying chain hopping, smurfing, and peel chain patterns
  • Wallet Degree Queries: PySpark showed a slight advantage (0.02x speedup) for simple aggregation operations

Key Insight: Neo4j excels at graph traversal and relationship queries, while PySpark is better suited for simple aggregations and batch processing. A hybrid approach is recommended: Neo4j for real-time queries, PySpark for batch analytics.

Implementation

  • Data Ingestion: Built automated pipelines using Web3.py to fetch Ethereum transaction data from Etherscan and Infura APIs
  • Medallion Architecture: Implemented Bronze/Silver/Gold layering for data quality progression—raw ingestion, cleansing/validation, and enriched analytics
  • Threat Detection: Developed pattern detection algorithms for chain hopping, smurfing, and peel chain techniques used in money laundering
  • Graph Modeling: Designed Neo4j schema with wallets as nodes and transactions as relationships for efficient traversal queries
  • Visualization: Created Kibana dashboards for transaction flow visualization and pattern analysis
  • Docker Deployment: Containerized the entire stack with one-command deployment

Use Cases

  • AML/CFT compliance monitoring for financial institutions
  • Forensic transaction tracing for law enforcement
  • DeFi protocol analysis and risk assessment
  • Wallet behavior profiling and anomaly detection

Outcome

The platform provides actionable intelligence for blockchain forensics, with clear guidance on when to use graph databases vs. batch processing. The benchmarking results informed architectural decisions for production deployments, and the hybrid approach maximizes both query performance and processing scalability.
