The Problem

A portfolio of 20 estates-data projects is a liability, not an asset, if each one is a standalone demo with its own naming, its own fixtures and no acceptance criteria. Anything untested quietly rots, and the next person cannot tell whether a broken dashboard means a broken pipeline or a changed schema.

Real institutional data is not available for portfolio work, which removes the usual escape route: nobody can check whether a number is right. Without ground truth and a gate in CI, "the build is green" says nothing about correctness — it only says nothing crashed.

Approach & Implementation

  • Synthetic by Design: every figure comes from a campus_synth foundation generator that also emits ground truth; public open sources came later. Provenance is tracked in DATA.md and every chart carries a "synthetic data" footer.
  • Foundation (P00): 20 tests pass at 96% coverage with ruff and mypy clean; a small generate run takes 17–20 s, so the loop stays fast enough to use.
  • Campus Warehouse (P01): 7 platform tests, 35 s ingest, and all 8 sources reconciled with zero row loss.
  • dbt Project (P04): dbt build green — 196 pass / 0 error from 147 tests plus 2 unit tests, 100% of models tested, 100% of columns documented, 21 contracts.
  • CI/CD for Data (P05): ci, nightly, docs, release and security workflows plus reusable workflows, pre-commit and sqlfluff. Verified gate chain: ruff + mypy clean → pytest 27 pass (84%) → dbt build 196 pass → sqlfluff + mkdocs + compose clean, with the data-quality gate running inside CI.
  • Space Utilisation (P06): frequency × occupancy on gold marts, 7 calculation tests and 5 validation SQL, handed off to Power BI.
  • Net Zero & Carbon (P08): scopes, intensity, pathway and baseload on gold marts with 7 calculation tests and 4 validation SQL — baseload came out as the top band at 48.8%.
  • Spatial Analysis (P19): OSM building footprints plus synthetic metrics, area-rank matching, 8 buildings, 4 heat clusters and 5/10-minute isochrones, exported as gpkg, geojson, topojson, png, folium, qml and csv with a Power BI map handoff.
  • Honest Scope: 7 of 20 projects are complete; the remaining 13 are marked not-started in STATUS.md rather than quietly implied. Project status is dated 2026-10-03 → 05.

Challenges & Solutions

Challenge: 20 Projects Becoming Unmaintainable Demos

Twenty separate mini-projects tend to fragment into code that only its original author can run, with no shared assumptions.

Solution: One Foundation Generator + Per-Project Acceptance Docs

All data descends from a campus_synth generator that also produces ground truth, and each project ships an acceptance document defining what "done" means.

Challenge: Silent dbt Breakage

Refactors and schema changes break models quietly — a green build can still be serving wrong columns to a mart.

Solution: 196 Tests + 21 Contracts Gated in CI

Every model is tested and every column documented; contracts run as part of the CI chain, so a breaking change fails the build instead of shipping quietly.

Challenge: Reconciling 8 Ingested Sources

With eight feeds landing in one warehouse, rows get dropped or double-counted and nobody notices until a total looks wrong.

Solution: Zero-Loss Reconciliation Against Ground Truth

Because the generator knows the expected counts, ingestion is reconciled source by source and all 8 land with zero loss, verified rather than assumed.

Challenge: Spatial Work Unusable by Non-GIS Analysts

Footprints, clusters and isochrones are meaningless to anyone without a GIS toolchain open next to the dashboard.

Solution: Standard GIS Exports + Power BI Map Handoff

Results are exported as gpkg, geojson, topojson, PNG and QML alongside a Power BI map handoff, so the analysis leaves the GIS world and lands where the business already works.

Outcome

7 of 20 projects delivered with the whole chain reproducible from a single make ci, 196 dbt tests passing, 21 contracts enforced, and 8/8 sources reconciled with zero loss against ground truth. Provenance is documented in DATA.md and every chart is labelled synthetic.

What is not finished is stated plainly: the remaining 13 projects are marked not-started in STATUS.md rather than implied. The delivered chain is real; the plan is still a plan.
